# 成熟布局与最小改动

仅用于 `LOCK_LAYOUT_EDIT` 和 `STRICT_REPLICA`。本文件是布局冻结和局部修改的权威来源。

## 守恒公式

> 最终画面 = 图1全部冻结内容 + 批注明确要求的变化 - 批注明确要求的删除

冻结图1成熟主画面的：

- 画幅、透视、摄像机和观察角度；
- 底座与主体外轮廓；
- 主体、角色和附属构件的数量；
- 位置、大小、比例、朝向、间距；
- 前中后景、遮挡、视觉重心；
- 安装点、承托关系和未被批注点名的功能。

环境背景不属于冻结内容，必须服从 `PROJECT-BG`。

## 布局权限表

进入提示词前，为每项变化选择且只选择一个权限：

| 权限 | 可做 | 不可做 |
|---|---|---|
| `FROZEN` | 只描述保留终态 | 移动、旋转、缩放、改遮挡 |
| `POSE_ONLY` | 在角色原位置中心和原占位内调整头部、目光、表情、四肢和轻微重心 | 改角色中心、比例、外接占地或跨区接触 |
| `SURFACE_ONLY` | 在指定原表面/原安装点内改材质、浅浮雕、包边、固定和拆件 | 扩散到同类其他部件或增加新占位 |
| `BOUNDED_RECENTER` | 仅用户明确授权时，在点名边界内有限重排 | 用于默认丰富或泛化“聚拢” |

`LOCK_LAYOUT_EDIT` 默认只有前三种权限，绝不自动获得 `BOUNDED_RECENTER`。一项要求若同时需要“位置不变”和“跨越原间距完成接触/聚拢”，属于权限冲突：先换成可达事件；没有可行事件时列为待确认，不能把两句同时写入正向提示词。

## 允许修改

修改只能发生在目标部件原占位内：

- 补厚度、拼缝、拆件线和倒角；
- 补支撑、接触点、插接点、固定点和材质收口；
- 在不改变外接轮廓的前提下规整局部；
- 按批注更换角色、文字、Logo、颜色、材质或姿态；
- 把看不到的背面结构写进建模清单。

禁止为了“可建模”“更丰富”或“更有趣”而：

- 移动、缩放、增删、拆散或重新排列已有模型构件；
- 转动摄像机、旋转全场或改变透视；
- 新增改变剪影或占地的平台、脚手架、横梁、楼层、对称件和大型道具；
- 移动物件来暴露被遮挡的背面；
- 把局部修改扩散到其他同类实例。

## 局部变化规格

### 同类对象分组

先按锚点和职责建立互斥目标集合，分别写最终数量。不得用同一泛称同时要求保留和删除。

### 局部模型轴

方向或姿态调整写明：

- 只变化目标部件自身局部模型轴；
- 原安装点、占位和尺寸不变；
- 摄像机、主体、其他实例及原功能不变。

若模型可通过转摄像机或旋转全场“表面完成”，该提示词不合格。

### 载体守恒

替换文字、Logo、图案或局部造型时，冻结原牌匾、旗帜、箱体或外壳的：

- 宽高和外轮廓；
- 安装点和占位；
- 与周围构件的遮挡和间距。

新内容只能通过内部字宽、字距、字号或图案构图适配。除非批注明确要求，不得自动放大、移动或重做载体。

### 功能继承

批注只改方向、外观、颜色或材质时，原有出水、发光、开合、运动、喷射和操作关系保持不变。没有当前来源，不得新增功能。

## 成熟改稿中的趣味

- 优先利用已有角色与已有物件形成可见动作、接触或因果关系。
- 可选0～2个不产生新占位、不改变剪影、遮挡或重心的表面/附着点缀。
- 用户明确要求新增的鹦鹉、嫩芽、徽章等属于硬需求，不是自由创意配额。
- 若动作必须移动角色或物件才成立，取消或改写动作。
- `STRICT_REPLICA` 不添加任何未被用户点名的故事、角色、道具、底座或装饰。

丰富开启时，`LOCK_LAYOUT_EDIT` 的创意方向不得只写材质、圆角、包边、厚度或拼缝；必须利用 `POSE_ONLY`、`SURFACE_ONLY` 或已有功能形成一条原位可读关系。先检查手/爪/工具到目标的距离、栏杆和墙体阻挡、原遮挡及角色视线；不自然可达则换事件，不得拉长肢体或暗中移动。

删除图1外部环境后，如果原主体、角色和道具在灰色背景上形成多个分散物件岛，仍须保留图1成熟布局。此时“聚拢”只能指加强已有共同承托、接触阴影、材质和重复设计语言，不得命令重排；若用户要求真正聚拢，需升级为明确授权的有限重构。

## 模型捷径反例

| 表面要求 | 错误捷径 | 必须补充 |
|---|---|---|
| 前部件朝向观众 | 转正摄像机 | 只转该部件局部轴，冻结摄像机和全场 |
| 删除远处灯笼 | 删除全部灯笼 | 按锚点分组并分别点数 |
| 换长文字 | 放大牌匾 | 冻结载体，只调内部排版 |
| 让结构更清楚 | 拆开或重排全场 | 原位补厚度，背面写清单 |
| 换材质 | 顺便新增灯光功能 | 明确功能保持不变 |
