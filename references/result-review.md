# 临时结果诊断

用于两种情况：用户主动回传生成结果并要求诊断；或网站完成 Pix 生图后自动执行需求符合度审查。自动审查只比较本任务图1、已通过审查的正向提示词和本轮生成结果，不把结果图变成下一单参考，也不自动扣费重生。

## 输出

只给：

1. 总判断；
2. 需求终态差距；
3. 布局、主体、材质、背景和可建结构差距；
4. 原因归类；
5. 一段正向定向修正。

冻结结果中已经正确的镜头、布局、主体、角色、颜色和材质，只修失败项，不借复检重新设计。

网站自动审查使用结构化结果：整体 `pass`、逐图 `per_image`、`errors`、`warnings`、`summary` 和 `best_indices`。至少检查硬修改、红线删除、角色/物件数量、布局权限、局部参考范围、创意事件、聚拢、背景、文字/Logo和可建接触。四张图可以分别通过或失败；Pix 平台内容审核通过与需求符合度通过必须分开显示。审查失败时保留并展示图片，状态标为“需修改”，输出最小修正方向，不自动重新生图。

## 归因

- 提示词缺少目标集合、可观察终态、冻结项或影响范围，或仍允许模型捷径：归为提示词/审查失败。
- 提示词已经唯一锁定终态，生成结果仍违反：归为生成执行偏差。

两类问题分开报告。不得用“生成随机性”掩盖提示词歧义，也不得把全部结果偏差归咎于提示词。

## 人工成品

用户同时提供人工成品时，只作为当轮可建模完成度下限，比较：

- 叙事密度、功能模块密度、空间聚拢度；
- 有限底座和一体化承托；
- 部件厚度、分面、圆角、接缝和拆件；
- 表面高光与特效固定方式。

人工图的人物、物件、文字、周年值、配色、布局、环境和背景不得反向写入正式流程。

## 修正格式

使用正向、唯一的可见终态，例如“主招牌最终只显示指定字符串”“底座边界外保持空白”。除非用户本轮明确说明会使用负面提示词并主动要求，否则不追加“负面补充”或新的独立负面整段。
